# CivicSense: Your Voice, Your City

We are building a civic issue reporting platform called "CivicSense".

You are responsible ONLY for the frontend foundation in this task.

DO NOT build:

- Backend

- Database

- Authentication logic

- API integrations

- AI features

- Real notifications

- Complaint submission functionality

- Officer functionality beyond basic placeholder navigation

Build the frontend foundation with a clean, modern, professional civic-tech design.

Create:

1. Landing page

- Project name: CivicSense

- Short tagline explaining that citizens can report civic issues and track their resolution.

- Two clear entry options:

  - Citizen Portal

  - Officer Portal

- Professional but simple visual design.

- Mobile responsive.

2. Application layout

Create a reusable application shell with:

- Header

- Logo/project name

- Navigation area

- Main content area

- Footer where appropriate

3. Routing/page structure

Create placeholder routes/pages for:

- /

- /citizen

- /officer

- /citizen/login

- /citizen/register

- /citizen/dashboard

- /citizen/report

- /citizen/complaints

- /officer/login

- /officer/register

- /officer/dashboard

- /officer/complaints

These pages should only contain simple placeholder content indicating what each page will eventually contain.

4. Reusable UI components

Create reusable components for:

- Buttons

- Cards

- Form inputs

- Select/dropdown

- Modal/dialog

- Status badge

- Loading state

- Empty state

- Error message

- Page header

5. Design requirements

- Clean civic/public-service aesthetic

- Professional rather than flashy

- Excellent readability

- Responsive on desktop, tablet and mobile

- Consistent spacing and typography

- Accessible color contrast

- Clear hover/focus states

- Avoid unnecessary animations

- Avoid excessive gradients or decorative effects

6. Navigation

Citizen Portal should have placeholder navigation for:

- Dashboard

- Report Issue

- My Complaints

Officer Portal should have placeholder navigation for:

- Dashboard

- Complaints

- Profile

7. Important development rule

Use mock/static data only where necessary for visual placeholders.

Do NOT create fake backend functionality.

Do NOT connect to Supabase, Firebase, APIs, authentication providers, or external services yet.

At the end, make sure the project runs successfully and every route above can be opened without errors.

This is F1: FRONTEND FOUNDATION ONLY.

Do not implement later project features yet

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
